# Principles

Each file is a set of writing principles the principles editor checks against.

- `base.md` always applies.
- A brief picks others with a line like `principles: persuasive, scientific`.
- With no such line, the mode picks: essay and application use `persuasive`; research uses `scientific`.
- `## Whole piece` feeds level 1. `## Prose` feeds level 2.

To add a context, copy a file, rename it, and edit the lists. Keep each list short; every line costs tokens on every run.
